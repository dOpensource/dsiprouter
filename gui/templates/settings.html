Retention
Enter a whole number of days from 0 to 36500.
CDRs older than this many days are deleted every night at 02:30. 0 keeps CDRs forever. Whole days are kept: with 7 days, everything from 7 days ago at midnight onward stays.
S3 cold storage
Each expired day is uploaded as gzipped CSV files (<prefix>YYYY/MM/cdrs-YYYY-MM-DD.csv.gz, plus acc- and missed_calls- files). Rows are only deleted after their upload succeeded.
A bucket is required for archiving.
Enter an http(s) URL.
An access key is required for archiving.
A secret key is required for archiving.
Stored encrypted and never shown again. Leave empty to keep the saved key.
Webhook
Every minute the CDRs written since the last delivery are sent as a JSON array, up to 100 per request. A failed request is retried with the same CDRs. CDRs written before the webhook was enabled are not sent.
Enter an http(s) URL.
A username without a colon is required for basic auth.
A password is required for basic auth.
Stored encrypted and never shown again. Leave empty to keep the saved password.
Turn this off to delete each CDR once the webhook accepted it. Only possible while the webhook is enabled.
